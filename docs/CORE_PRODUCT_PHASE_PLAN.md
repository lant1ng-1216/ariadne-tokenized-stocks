# Ariadne core-product phase plan

**Goal:** bring the local Ariadne core to delivery-ready quality across the standalone SDK, MCP for existing Agents, and direct research surfaces. Preserve the shared asset identity, evidence, and safety model. This plan does not authorize a public release, paid service, real-wallet signature, transaction broadcast, or funded settlement.

## Advancement rule

Work one coherent phase at a time. Finish the listed tasks, run the phase's checks, record evidence in the developer log and interim reports, then call `npm run jev:gate`. If deterministic checks pass and Jev returns `advance`, continue automatically to the next phase in this plan. If a check fails, Jev identifies a repairable gap, or confidence/evidence is insufficient, stay in the current phase: diagnose the specific finding, make an in-scope repair or add stronger evidence, rerun the affected checks, and request a meaningfully improved review. Do not lower thresholds or resubmit identical evidence. Pause for the user only for an actual product decision, authorization boundary, external prerequisite, safety issue, or a bounded repair loop that makes no progress. Jev is a review signal, not a replacement for tests or user authorization.

## Gate command pattern

```bash
npm run jev:gate -- \
  --phase PHASE_ID \
  --next NEXT_PHASE_ID \
  --objective "Phase objective" \
  --check typecheck \
  --check TEST_SCRIPT \
  --criterion '{"id":"criterion-id","requirement":"An approved phase requirement.","checkNames":["TEST_SCRIPT"],"evidenceSummary":"A factual summary of what the selected check verifies."}'
```

Every gate requires at least one unique acceptance criterion with linked selected checks and a factual non-sensitive evidence summary. Use only deterministic, read-only or offline checks on the repository's Jev allowlist. Record live API observations separately from Jev's evidence, and never pass secrets, wallet data or sensitive logs to Jev. The Jev confidence floor is `0.85`; environment configuration may raise, but cannot lower, the floor.
