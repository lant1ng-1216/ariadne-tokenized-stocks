# Ariadne 已知限制与未验证事项

本文区分已实现能力、外部依赖限制与尚未取得的证据。任何本地测试通过，都不能自动关闭供应商、宿主或真实资金环境中的未验证事项。

## 供应商目录与行情

- 2026-10-03 的一次 BSC 观测中，平台元数据的链级 token 数合计为 545，接口返回了 488 个唯一表示，差额 57 未解释。两个计数的统计口径、同步时点或接口覆盖可能不同，不能将差额直接称为“缺失 57 个资产”。
- 官方渲染版接口说明没有列出目录分页参数或总数契约；schema 下载当时超时。分页是否存在、目录是否完整、`tabId` 的运行时语义均未证实。
- 一次样本的 488 行中，442 行有可识别市场状态，46 行没有；目录项中没有逐项行情更新时间或流动性字段。缺失不是零。
- 价格接口的逐资产时间戳与响应级时间戳分开保留，但没有已验证的行情新鲜度 SLA。两条 NVDA 样本的观测不能代表持续服务水平。
- Demo 数据是固定的合成样本，不代表实时价格、真实完整目录或可执行交易。

详细来源和字段定义见[Binance RWA API 契约审查](BINANCE_RWA_API_CONTRACT_AUDIT.md)及 `research/data/` 中的结构化记录。

## Agent 与 MCP 宿主

- Agent 自然语言理解和工具自动选择由宿主决定；Ariadne 提供工具 schema、描述及高层研究工作流，但不保证每个 Agent 都能自动选择同一工具。
- MCP App 研究卡仅在支持相应 UI 扩展的宿主中呈现。当前确定性本地测试验证的是 Ariadne 资源与渲染逻辑，不是所有第三方宿主的布局、尺寸、交互和可访问性表现。
- 最终回答由 Agent 宿主生成；用户应能检查结构化来源、警告与副作用字段，而不只依赖模型摘要。

## 交易与资金安全

- 离线 `TESTB` 流程和本地合成服务验证模拟及拒绝路径。2026-10-09 另有一笔 owner 授权的 bStocks NVDAB 真实资金购买，BSC 主交易成功且 MetaMask 显示到账资产；这不验证 Ondo/RFQ、其他股票、其他钱包/宿主或长期可靠性。购买计划后的 Agent 后台登记、链上核验与去重终局消息已实现，但该新版路径尚未经过下一笔 owner 真实交易验证。
- 当前受保护的 `GuardedEvmExecutionService` 面向单个标准 BSC EVM 操作及有可验证 spender 的 ERC-20 输入路径。原生输入、RFQ 和多操作计划不由该 helper 覆盖。
- SDK 的通用 `ExecutionService` 和原始交易广播 API 是集成方控制的低层接口，不自动继承标准 Guarded 流程的全部校验。
- Ariadne 不持有私钥或代替用户签名；钱包签名和链上广播需要独立的用户授权。

## 分发与运营

- SDK 可以在本地打包并通过隔离消费者安装/导入验证，但尚未发布到 npm。
- Hosted MCP 仅有本地 Streamable HTTP Demo，不是公开服务。生产托管仍需认证、租户隔离、限流、监控及凭证设计。
- 本地测得的延迟样本没有覆盖 Agent 推理与回答渲染，不构成端到端时延承诺。
